# Infomatrix 中文翻译助手

一个单文件、无需安装、离线可用的本地网页工具，帮助中文用户理解 **Infomatrix**（SOLACYT 主办的伊比利亚美洲学生科技/创新项目竞赛）官网内容。

官网：<https://www.infomatrix.lat/>（以西班牙语为主，部分英语）

## 功能

- 📖 **官网汉化指南**：竞赛介绍、八大类别、报名→缴费→交作品流程、FAQ 精选、12 项国际评分标准、联系方式等的中文翻译汇总。
- 🖼️ **截图翻译**：上传/拖拽/粘贴截图，浏览器本地 OCR（Tesseract.js）识别西班牙语或英语，再译成中文；也支持直接粘贴原文（更精准）。
- 🔤 **术语速查**：官网高频西语/英语词汇对照表，翻译结果中的专有名词会自动高亮。

## 使用方法

- 在线使用（GitHub Pages）：<https://kobe-qwq.github.io/infomatrix-zh-translator/>
- 或直接下载 `index.html`，用浏览器（Edge/Chrome）双击打开即可，无需联网即可阅读指南。

> 说明：截图翻译与「粘贴原文」的机器翻译需要联网；首次截图识别会下载约 10MB 的 OCR 模型。所有识别与翻译均在浏览器本地完成，内容不会上传到任何服务器。
